## About

I'm a Computer Science student specializing in **Network Technology & Cybersecurity**. I recently completed a technical support internship at an ISP, where I troubleshot Layer 1–3 connectivity issues for real customers using OSI-model diagnostics.

Outside of work, I build what I want to understand better. I've deployed and hardened a **Windows Server 2022 Active Directory** environment from scratch (DHCP, GPOs, OU-based access control), and designed a segmented enterprise network lab — Core/Distribution/Access layers, VLANs, ACLs — protected by a custom-tuned **Snort IDS** and UFW firewall. I'm also building **Security Playground**, a browser-based platform for people learning offensive security the way I did — by doing, not just reading.
